# CONSTITUTION — 产品 DNA（所有决策的最高约束）

> 本文件是产品的宪法。任何里程碑、任何代码决策与宪法冲突时，宪法优先；
> 宪法本身只能由 Bruce（产品所有者）修改。
> 2026-09-19 PM 讨论定稿：Bruce 口述的产品方向已固化进本文件，
> 并据此开列 ROADMAP 第二程序列（B01-B04）。

## 愿景

把 Bruce 脑中的想法，变成**高质量、可像日常播客一样消费的个性化英语输入材料**；
同一流水线顺带成为自媒体内容的一键生产线。

**产品主线（5 步闭环）**：选一道雅思题 → 用中文或英文自由作答 → Agent 会话改写为
母语者自然英文 → Fish TTS 生成音频 → 像播客一样反复听（模仿、跟读、提口语分）。
所有功能为这条闭环服务。

## 核心不变量（第一性原则，永远成立）

**输入我的表达/意图/回答之后，必须直接得到的是母语者表达的音频**——
母语者非常逼真、非常拟人地把我们表达过的意思表达一遍。

- 形式匹配：对话进对话出，独白进独出发
- 这个音频**永远自动生成、永远优先**；教学播客等一切衍生品是手动、按需、后置的
- 由此衍生：改写质量与 TTS 自然度高于一切新功能

## 不可协商原则

1. **音频质量是最高优先级。** 对齐精度、自然度、响度、无异常段落，优先于任何新功能。
2. **本地优先、零服务器、零额外 API 成本。** 不引入云依赖；唯一外部服务是 Fish Audio TTS（免费档）。
3. **改写环节由 Agent 会话承担。** 工具与 Agent 之间是文件接口（data/ 下的纯文本），
   不集成 LLM API（Bruce 无可用 API 额度，明确拒绝）。
4. **学习方式 = 像听播客一样反复听。** 不做软件引导式学习功能：无学习模式、
   无间隔复习系统、无 shadowing 打分、无 ASR 发音评分。
5. **数据即产品。** data/ 下纯文本结构（问题/中文/英文/剧本）人类可直接读写，
   Agent 可批量读写；任何功能不得破坏这个双向接口。
6. **分享形态零成本。** GitHub 开源 + APK + 可移植 zip，追求影响力与流量，不盈利。
7. **Bruce 的参与只留在门上**：听感抽查、UI 走查、里程碑验收。其余由 ROADMAP/PROGRESS 驱动 Agent 自主完成。
8. **语音角色规则**：回答必须是**男声（Ethan）**，方便 Bruce 模仿；提问用女声。
   实现为 answer_voice_male 设置，方向规则在合成层强制（女问男答）。

## 产品优先级（2026-09-19 Bruce 定稿，降序）

1. **PC 题库**——学习 RoastDuck：选题→作答→音频闭环；网页 UI 美化靠后
2. **手机 APP**——必须是独立应用（Android），不是局域网网页
3. **分享开源**——GitHub + APK，"让别人立马体验上"
4. **教学播客/视频**——自媒体内容线，最后做

## 手机 APP 形态决策

- **独立 APP**（Android APK，Capacitor 包裹现有前端），离线全功能；局域网网页/PWA 只是
  过渡形态，不是终态
- 播放页对标"每日英语听力"：大字号宽行距文稿、**音字同步高亮（逐词点亮）**、点句跳转、
  中英翻译层切换
- 必需功能 = 文稿 + 音字同步高亮；跟读录音 / AB 循环 / 生词收藏 / 倍速预设 / 单词训练 /
  笔记 / AI 摘要全部记"将来可选"，v1 不做
- 内容经电脑端导出**语料包**（zip：文本 + 对齐 + 音频 + 题库快照）导入 APP，
  支持局域网直传与文件导入两种方式

## 教学内容设计原则（B04 执行时遵循）

- **锚定具体雅思题**：每期让观众对某道具体题掌握更多可用表达。通用词汇内容
  （刷牙/推拉类动词）只作账号拓展，不作主线
- **个性化经历不可复制，短语通用**：如描述家乡——山城小县城与发达大城市各有通用描述词；
  主持人可拓展"如果你的家乡是另一种类型，可以怎么说"，把单期覆盖面从"我的答案"
  扩到"这类题的所有答法"
- **纯英文双主持优先**（雅思考生英语水平有保证）；中英结合面向大众（还没怎么学英语
  但想学的人），作为变体后置，不弃
- 中英混读问题的解法是**脚本结构消灭而非模型硬扛**：任何一行台词必须纯单语
- **内容标准**：不求解决用户的英语问题，只求让用户**觉得学到了**——每期一个可带走的
  chunk，15 秒内能复述
- 视频形态：16:9 横屏、1-3 分钟
- **已取消**：字幕卡视频渲染器（2026-09-19 Bruce 决定，旧实现已删）；
  中文主持音色、纠错式学员声（含 Bruce 原声方案）降级为远期可选

## 技术栈约束

- Python 3.11 + FastAPI + 原生 JS 前端（无构建步骤、无 CDN）
- 手机端 = Capacitor 包裹现有前端，**不引入第二个前端代码库**
- ffmpeg 为唯一音频处理依赖；新增重型依赖（torch 类）必须做成可选模块并给出降级路径
- Windows 优先（当前主机），路径处理必须兼容 CJK
