# L04：今日练习与困难句间隔口答

2026-09-30。本文描述生产应用中的桌面交互。页面沿用暖纸视觉；图片是运行页面的
合成验收数据，不是 Bruce 的录音或学习结果。

## 页面与入口

- 电脑端服务模式无 hash 时进入今日练习；`#/today` 可直接打开。
- 今日页依次显示未完成学习、到期困难句、题库入口。没有记录、没有到期句和材料待补齐
  各有对应说明；有未完成口答轮次时优先继续该轮。
- `#/oral-review/<id>` 是可恢复的口答轮次。按到期日期排序，每轮最多 10 句。
- `#/study-history` 展示实际默写、口答、自评和录音记录，可按日期、题目筛选。
- 句子详情保留整句默写，增加加入／暂停／恢复口答日程和现在口答的入口。
- Android 和 pack 模式继续使用原有题库、导入与收听流程；新入口仅在桌面导航显示。

## 口答操作

1. 开始时只显示中文与来源题目，页面不包含示范英文和讲解。
2. 默认可录音，也可自己开口后选择“我已口答，不录音”。无录音结果标为本人自评。
3. 停止并保存录音后，显示示范、讲解、音频和自评。未保存录音可以回听、重录或下载。
4. 自评是“独立说出／需要提示／暂时说不出”。意思完整、表达合理即可独立说出，
   不要求复现同一措辞。回答前看过示范，则独立说出不可选。
5. 查看提示默认 5 秒，沿用 3／5／8 秒偏好。刷新后提示使用事实仍保留。
6. 本轮跳过保留原日期。结束页只列本轮实际结果，可返回今日页练下一轮。

提示、无录音确认、已保存录音、当前句和自评提交由服务端保存。重复提交不会重复计数。
麦克风拒绝后可以重试权限，也可以无录音口答；保存失败保留当前录音并提供重试与下载。
离开或刷新时，未保存或正在录制的录音有提示。切换回听音源时先暂停另一个音源。

## 日程与历史

- 困难句需先通过初次默写，才自动进入日程；句子详情也可手动加入。
- 新句次日到期。独立成功后间隔依次为 3、7、14、30 天，之后维持 30 天；
  需要提示或说不出则回到次日。规则是首版产品选择，不宣称为唯一最优学习间隔。
- 用电脑服务的本地日历日期判断到期。跨午夜的轮次保留原句单，按实际提交日安排下次。
- 同句同日首次有效提交才调整日程；后续重练保留记录。接口重试使用唯一 ID。
- 旧困难句没有日期时作为首次复习候选，并注明历史无日期，不编造旧口答或练习时长。
- 源文本指纹变化后旧日程不可执行，保留快照与历史。新版需重新学习或手动加入。
  重制音色不重置日期。已删除来源可跳过；已删除录音不再作为可回听证据展示。

## 本机数据与接口

日程、轮次和自评保存在 `data/study_private/oral_review.json`，版本号为 1，原子写入。
每张句子卡绑定条目、源文本指纹和句号，并保存当时中英文。每次提交保留时间、本人自评、
提示使用、录音关联与当次下次日期。文件不进入 Git、公共语料包或可移植发布包。
原有三类整题录音保留；口答录音单独标为 `oral_review`，带句号及轮次关联。

| 接口 | 用途 |
| --- | --- |
| `GET /api/study/today` | 今日到期数量、候选、未完成学习与材料恢复入口 |
| `POST /api/study/review-sessions` | 创建／恢复轮次；可指定一题的一句进行主动重练 |
| `GET /api/study/review-sessions/{id}` | 恢复当前句、提示与已保存录音状态 |
| `POST /api/study/review-sessions/{id}/actions` | 提示、无录音确认、查看示范、跳过 |
| `POST /api/study/review-sessions/{id}/attempts` | 幂等保存自评，并同时更新日期和轮次 |
| `POST /api/study/review-sessions/{id}/recording` | 保存独立口答录音 |
| `GET/POST .../items/{id}/study/oral-review` | 查询／手动加入句子日程 |
| `PATCH /api/study/review-cards/{id}` | 暂停／恢复日程 |
| `GET /api/study/history` | 按 `day`、`topic_id`、`item_id` 查询记录 |
