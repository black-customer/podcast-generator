## 完整闭环

1. 选题先试答录音，停止写本机，提交后关联条目，失败可重试关联而不重复生成。
   可明确无录音继续；已有参考的补录不能默认冒充盲答。实际文字、中文补充意图、外部建议
   分存；无自动转写，外部建议不作为错误证据。
2. 理解固定参考，原意忠实且表达可驾驭；普通复答不自动改稿。区分有证据错误、
   待本人确认的缺口、可选润色；默认选最多三处，可增减，其余全文保留。点句、完整音频、
   中文和解释按需使用；定位不可靠时明确播放完整片段。
3. 中文先口答，可独立说出即可通过；需要时整句默写，对照后隐藏英文再口答。
   默写与口答事实分开，不同表达不自动判错，替代表达由本人确认。提示保留草稿，沿用
   3／5／8秒设置。看过／听过参考不记独立，可稍后再练，局部录音为可选。
4. 提纲口答后只看原题，默认录音且停录保存，也可明确无录音自评。检查切题展开、主要问题、
   连贯、可理解性，三档本人评价无自动分数；卡住只补局部，提供首尾录音与提示条件。
   Part 1无固定句数／时长；Part 2一分钟准备、笔记、最多两分钟回答；Part 3回答相关追问，
   旧材料可粘贴外部追问。
5. 首次独立后1天复验，延迟成功后3天，再成功标稳定掌握·本人复验；此后7／14／30天。
   同日不累加，逾期不补算；失败撤销稳定、补局部，修复后次日重验。整题成功当天不重复
   安排困难句，不改历史；可暂停恢复。浏览、自由播放、轻练不推进日程。

保存成功才推进；失败保留草稿／录音，主要动作可撤销，提交幂等。
首页依次提供继续训练、到期复验、新题；句子轻练和聊天为次入口。题库增加训练状态和到期标识。

## 接口与兼容

- GET `/api/study/training`：题目状态与日程。
- GET `/api/topics/{tid}/items/{iid}/study/training`：材料、状态、录音、历史。
- POST 同路径 `/actions`：`version:2`、`fingerprint`、`action_id`、`action`及参数。
  校验阶段、提示、录音归属与句子范围，重复不累加，旧指纹拒绝。
- 材料v1可选增加`gap_kind`、`outline`、`groups`、`followup`；分块以零基序号引用实际句子。
  Agent/API统一校验，三英文文本契约不变，旧材料不批量收费重生成，不从文字诊断发音。
- 私有progress v1保留旧字段，新增`training` v2、`training_history`。旧默写不算口答，
  历史summary仅为待复验；改稿／音频变化失效当前验收并归档，首次生成中保留首答。
- 题库`training_status=all|unstarted|training|awaiting_review|mastered`，默认最新回答，
  可选择其他回答版本；到期与状态分开。Python与Android Rhino使用对应规则和共享场景验证。
- 个人交换有训练时v2，否则v1；读取v1/v2，未知版本拒绝，完整校验后落盘。跨设备历史归档
  查阅，不自动晋升当前掌握，不携带录音文件或本机录音路径。公开语料包不含私人训练记录。
- 有效用时只作本地估算；后台、暂停不计，120秒无操作且无播放录音时停止累计，无遥测。

不新增服务、框架、ASR、自动打分、AI通话或统计平台。

## 计划覆盖与验证

| 首答、无录音、意图／建议、失败保留 | 选题页本机草稿、生成请求、训练输入 |

## 效率对照试用

选未练过且Part／难度相近的成对题，交替使用已有AI反馈后自学和新流程，提供相同反馈资源。
计入看反馈、整理、练习、操作及返工总时间；在相同延迟（例如次日和三日后）录音，以相同
检查项评价。可请不知道分组的老师评录音，利用已有录音、尝试、估算用时人工整理结果。
先验证可执行性，无真实对照数据前不宣称提分或节省固定比例时间。
