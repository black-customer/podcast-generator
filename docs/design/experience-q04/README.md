# Q04 全应用体验打磨

2026-10-02。沿用暖纸视觉，调整现有页面布局、操作层级和恢复提示。
没有新增学习规则、评分、模型调用或数据格式；手机仍只验收导入、浏览与收听。

## 入口与布局

| 原有入口 | 现在如何找到 |
| --- | --- |
| 今日练习／口答轮次／学习记录 | 今日练习主导航；页首学习记录；到期区继续本轮 |
| 开始练习／题库 | 主导航「题库」；`#/practice` 与 `#/bank` 均保留 |
| 话题／回答／完成页／学习 | 我的语料 → 话题 → 播放或学习；完成页继续保留播放、下载、学习 |
| 句子复习／详情／整句默写／口答 | 主导航「句子库」→ 句子详情 → 已有练习入口 |
| 当前音频／整集章节 | 正在播放；话题中的整集入口仍保留 |
| 设置／音色展台／高级维护 | 侧栏底部设置；设置页中的音色展台及高级内容管理 |
| 手机导入／离线收听 | 原有导入页、话题列表和播放器；不开放桌面学习入口 |

桌面内容最大宽度 1120px，常规内边距 32px，窄桌面 24px；长文约 72ch。
暖纸色板不变，正文 16px、辅助说明 14px、常规操作高度 44px。
兼容样式保留；Q04 桌面规则集中按外壳、组件、页面、窄屏与减少动态效果组织。

题库先筛选，再在列表旁填写回答；窄窗口作答区转为上下排列。
设置按服务、角色声音、已有偏好、技术参数、高级维护分组；后两项默认折叠。
历史将默写事实、口答次数与句子数、自评及录音条件分开列示。

## 操作与恢复

- 今日页压缩空区域，按钮显示实际本轮句数；继续任务、到期复习、新题依序突出。
- 录音主操作随准备／录制／停止切换为开始／停止／保存；无录音路径仍可见。
  自评三项同等权重；未保存录音离页、改为无录音或跳过时仍需明确处理。
- 写请求开始前显示处理状态并阻止重复点击；失败保留本页输入与录音。
  无录音切换等请求失败不提前丢弃录音；下载后缀跟随 WebM／Ogg／MP4 实际格式。
- 导航显示目标页标题再填充数据。题库及历史筛选保留控件，加载期间旧结果不可操作；
  读取失败有重试，历史保留所选日期，题库保留同一道题的回答草稿。
- 页面完成读取后焦点进入标题；下一默写句进入首词，拼写问题进入对应词框，
  通过后进入讲解。Shift+Tab 可后退；提示不抢焦点；输入不触发播放器快捷键。
- 所有异步页面沿用路由令牌；补齐整集迟到响应的保护。
- 首次配置恢复已保存音色及性别，共享同页音色读取；失败可重试。
  占位音频与真实语音明确区分，外部生成所需文本发送也如实说明。
- 服务健康检查成功后才自动打开浏览器；参数、Python 或依赖失败提供处理提示。
  更新依赖失败不继续重启。便携包启动使用临时目录和现有测试运行时验证，
  不等同于在全新 Windows 上下载依赖的安装演练。
- 手机中文话题 ID 在包接口与音频地址中正确解码；已有中文参考按钮连接现有显隐开关。

## 性能结果

使用临时目录生成 100／500 条完整合成条目。每项先记录首次读取，再运行 20 次；
p95 取排序后第 19 个值。原始结果见 [改动前](before-performance.json)、
[改动后](after-performance.json)，复现工具为 `scripts/benchmark_experience.py`。

| 条目数／操作 | 前 p50／p95（毫秒） | 后 p50／p95（毫秒） |
| --- | --- | --- |
| 100／语料列表 | 22.28／22.87 | 22.44／22.99 |
| 100／今日汇总 | 1084.79／1252.24 | 407.74／418.48 |
| 100／历史 | 694.44／725.47 | 394.62／405.89 |
| 500／语料列表 | 119.46／123.79 | 111.89／113.91 |
| 500／今日汇总 | 5835.45／7047.74 | 2178.73／2202.12 |
| 500／历史 | 3717.33／4154.04 | 2189.28／2388.79 |

今日汇总将单个条目的材料读取从 4 次降至 1 次，仅在一次调用中复用。
下一次请求重新校验材料；实际口答提交仍重新验证来源。源标题读取不再触发无关的材料校验。
语料列表缓存策略未改变。以上是本机文件系统测量，非跨设备速度保证；500 条时今日页
仍需约 2 秒完成读取，页面壳与操作反馈先出现，不用假进度掩盖等待。
