## 愿景

把学习者脑中的想法，变成**高质量、可像日常播客一样消费的个性化英语输入材料**；
Bruce 是首位用户，但公开版本必须让普通 IELTS 学习者也能用自己的回答完成同一闭环。

**产品主线（5 步闭环）**：选一道雅思题 → 用中文或英文自由作答 → Agent 会话改写为
母语者自然英文 → StepFun（或 Fish）TTS 生成音频 → 自由收听，并可按需进入学习模式。
所有功能为这条闭环服务。

## 核心不变量（第一性原则，永远成立）

**输入我的表达/意图/回答之后，必须直接得到的是母语者表达的音频**——
母语者非常逼真、非常拟人地把我们表达过的意思表达一遍。

- 形式匹配：对话进对话出，独白进独出发
- 这个音频**永远自动生成、永远优先**；音频完成后仍可直接播放、下载。
  逐句中文和文本讲解是同一道题应准备的学习材料；学习操作由用户主动进入。
- 由此衍生：改写质量与 TTS 自然度高于一切新功能

## 不可协商原则

1. **音频质量是最高优先级。** 对齐精度、自然度、响度、无异常段落，优先于任何新功能。
2. **本地优先、零自建服务器。** 用户数据和密钥留在本机；StepFun 是默认 TTS，Fish Audio
   作为兼容备选。所有外部调用都使用用户自己的额度，项目不承担共享云成本。
3. **改写支持 Agent/API 双模式。** Agent 模式默认且不调用文本 API；用户主动配置 StepFun
   Key 后可选 API 模式。两种模式写入同一套 data/ 纯文本接口并生成相同结果。
4. **同时支持自由收听与主动学习。** 学习模式以一道题的完整回答为单位：
   学习前录音 → 逐句中文提示下的整句默写与讲解 → 看完整中文口答 →
   仅看原题脱稿口答 → 保存录音、复习困难句。整句默写覆盖所有句子，不按少数语块截断。
   文本讲解区分「原话有证据的错误」与「另一种正确表达」；自动发音或雅思评分
   不得在未经验证时展示。
5. **数据即产品。** data/ 下纯文本结构（问题/中文/英文/剧本）人类可直接读写，
   Agent 可批量读写；任何功能不得破坏这个双向接口。
6. **分享形态零成本。** GitHub 开源 + APK + 可移植 zip，追求影响力与流量，不盈利。
7. **Bruce 的参与只留在门上**：听感抽查、UI 走查、里程碑验收。其余由 ROADMAP/PROGRESS 驱动 Agent 自主完成。
8. **语音角色由用户决定。** 提问者和回答者分别选择性别与音色；Bruce 的个人默认可保持
   女声提问、青年男声回答，但公开产品不得把这个偏好强制给其他用户。

## 产品优先级（2026-09-19 Bruce 定稿，降序）

1. **高质量音频生成闭环**——选题/自定义话题→回答→Agent/API→音频
2. **公开可用的 PC 产品**——安装简单、界面清楚、音频可下载
3. **分享开源**——GitHub + 可移植包 + APK，让别人快速体验
4. **手机 APP**——离线导入、分类与精听
5. **教学播客/视频**——Bruce 的自媒体内容线，继续后置

## 手机 APP 形态决策

- **独立 APP**（Android APK，Capacitor 包裹现有前端），离线全功能；局域网网页/PWA 只是
  过渡形态，不是终态
- 播放页对标"每日英语听力"：大字号宽行距文稿、**音字同步高亮（逐词点亮）**、点句跳转、
  中英翻译层切换
- 2026-09-19 的 APP v1 验收范围为文稿和音字同步高亮。桌面端新学习模式的
  录音与句子复习先按本轮设计推进；手机端学习布局留待桌面方案验证后设计。
- 内容经电脑端导出**语料包**（zip：文本 + 对齐 + 音频 + 题库快照）导入 APP，
  支持局域网直传与文件导入两种方式

## 教学内容设计原则（B04 执行时遵循）

- **锚定具体雅思题**：每期让观众对某道具体题掌握更多可用表达。通用词汇内容
  （刷牙/推拉类动词）只作账号拓展，不作主线
- **个性化经历不可复制，短语通用**：如描述家乡——山城小县城与发达大城市各有通用描述词；
  主持人可拓展"如果你的家乡是另一种类型，可以怎么说"，把单期覆盖面从"我的答案"
  扩到"这类题的所有答法"
- **纯英文双主持优先**（雅思考生英语水平有保证）；中英结合面向大众（还没怎么学英语
  但想学的人），作为变体后置，不弃
- 中英混读问题的解法是**脚本结构消灭而非模型硬扛**：任何一行台词必须纯单语
- **教学内容标准**：每期有可带走、15 秒内能复述的表达；真实学习效果另外看
  延迟后的理解与独立使用，不能只凭即时熟悉感或播放次数判断
- 视频形态：16:9 横屏、1-3 分钟
- **已取消**：字幕卡视频渲染器（2026-09-19 Bruce 决定，旧实现已删）；
  中文主持音色、纠错式学员声（含 Bruce 原声方案）降级为远期可选

## 技术栈约束

- Python 3.11 + FastAPI + 原生 JS 前端（无构建步骤、无 CDN）
- 手机端 = Capacitor 包裹现有前端，**不引入第二个前端代码库**
- ffmpeg 为唯一音频处理依赖；新增重型依赖（torch 类）必须做成可选模块并给出降级路径
- Windows 优先（当前主机），路径处理必须兼容 CJK
