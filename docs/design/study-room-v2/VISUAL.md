# 「暖纸自习室」视觉规范

本文件与根 `DESIGN.md` 一起约束后续桌面实现。参考图 V00 与三张基准图
A10、B03、B06 定义整体语气；后续图采用相同纸面、字色与操作色。

| 角色 | 色值 | 用处 |
| --- | --- | --- |
| 暖米色 | `#F3EBDD` | 页面背景 |
| 浅纸色 | `#FBF7EF` | 阅读与工作纸面 |
| 墨棕 | `#332E27` | 标题与正文 |
| 暖灰 | `#6E665A` | 次要说明 |
| 橄榄绿 | `#596348` | 当前步骤、主按钮、焦点 |
| 赭石 | `#866B40` | 谨慎提示、已使用提示 |

英文题目采用可读的系统衬线字体；中文、菜单、教学说明与输入框采用系统无衬线字体。
实际实现应选择本地可用字体并检查中英混排。桌面参考画布为约 1536×1024；
左侧窄导航，主区域优先呈现题目或当前句，保持长文可读行宽和呼吸空间。

输入词框依序布局，长句跨行；焦点边界明确。按钮写出动作，例如「检查答案」；
通过、错误、材料未完成等状态同时有文字。播放时的当前句轻微强调，其他句保持可读。
安静阅读依靠颜色、排版与间距；没有装饰照片和影响字形的背景纹理。

图片通过内置 ImageGen 生成的页面存在轻微布局变化。七个文字修订页和精听、设置页
使用同一色系的静态 HTML/CSS 源文件渲染，以确保关键文案与流程准确。
实际开发可重用组件与设计令牌，图片不是逐像素规范。视觉测试仍需要检查文字对比、
键盘焦点、减少动画和较窄桌面宽度。
