## 两种输入

- **全自动**：选题后由Agent编写自然英文、对应中文与笔记，明确标为原创示范；
  示例经历不冒充Bruce的真实回答。也可复用有完整字幕对齐的已有回答与录音。
- **本人回答**：先给题，收到中文、英文或转写后原话永远保留，忠实改写；
  不新增个人经历，不把不同但正确的表达标为错误。

本人新回答优先；没有回答时照常完成自动稿。已做自动稿不因晚到回答被覆盖。
完成时可附下一道候选题，回复与否不影响次日生产。

## 每次生产的五步

1. 读根AGENTS、宪法、路线图、进度、QUALITY_PLAYBOOK及ielts-audio规范；
   检查已有输出和工作树，保留他人的未完成文件。只从公开题库选题，先做Part1；
   原始ID、话题与月份可追溯，避免重复题。当前考季优先，能复用的真实音频也是有效来源。
2. 新示范通常60–90词，给一个明确观点或生活细节；中文自然且逐句对应。
   根据语义主动规划chinese_lines，通常12–16行，不能为了填版虚构本人经历。
   英文原句必须与已生成录音完全一致；改稿就建新版本并重新生成音频。
   笔记只讲1–3个实用表达，写清意义、使用条件和可迁移例句；有证据才分析本人错误。
3. 新音频通过现有library接口保存独立条目和原始输入，原创稿归“自媒体原创示范”。
   由Agent准备三份英文JSON，执行canonical的pipeline.py complete，不读或打印Key，
   不直接调用provider，不绕过data校验。文本由Agent写，不额外调用付费文本模型。
   每天一题，通常最多两次完整合成尝试，不批量试音。
   新稿可用一行A提问、每句一行B回答，让同一考生连续回答的句子有真实测量时间轴；
   Fish已有逐词数据也可直接用于逐句字幕。给本人回答另用pipeline.py study准备学习材料。
4. 内容计划写到忽略的output/inputs/；调用build.py导出四份材料。
   字幕只采用实测单句跨度或SSE词时间戳，拒绝按字数猜时间；缺真实对齐时先准备材料。
   默认保持原速，明显过快可用0.92或0.85；不拿静音、dry-run或旧稿配新字幕冒充录音。
5. 批量看三张长图与录音视频关键帧，查题目翻译、语义、分行、字号、截断、
   字幕对应和声音非静音。合格才交付四个文件的独立链接及ZIP。QA不能代替真实听感，
   Bruce抽听并确认视觉后再发布。每日不改产品源码、不提交输入、本人语料或成品，
   不自动登录或上传抖音，不发APK或Release。

当天已有ready=true且material_contract为four-materials-v2的完整作品就交付它，
不重复生成或消耗API；日期后带版本号的目录同样计入当天。旧四步视频不满足当前契约。

## 来源与月份

题干、中文题目、话题和考季读取data/question_bank_public.json。
现有1–4、5–8、9–12月标签是本地整理记录，不自动等于当季官方真题。
标题月份只表示题库收录范围，不推导为“10月考场真题”或未核验的“新题”；
没有月份显示考季未核实。需要当季确认时记录原来源URL、发布日期与核验日期。
只提取必要题干，中文提示、英文示范和笔记自行编写，不照搬第三方完整范文。

## 内容JSON与命令

~~~json
{
  "question_id": "题库ID",
  "headline": "中文题目或标题",
  "topic_label_zh": "适合展示的中文话题名",
  "answer_origin": "原创示范",
  "sentences": [{"en": "录音中的英文原句", "zh": "对应中文"}],
  "chinese_lines": ["逐行中文", "必须完整保留各句中文"],
  "chunks": [{
    "en": "答案原文中的表达",
    "display_en": "可选：词典形式，如end up doing sth.",
    "zh": "意义",
    "usage": "使用条件／搭配",
    "example": "迁移英文例句",
    "example_zh": "例句中文"
  }],
  "transfer_zh": "可选的下一次口答提示"
}
~~~

~~~bash
.venv/Scripts/python workflows/daily-ielts/build.py \
  --lesson workflows/daily-ielts/output/inputs/日期.json \
  --item-dir "data/topics/独立话题/items/目标条目" \
  --out workflows/daily-ielts/output/日期 \
  --speed 1
~~~

输出限本目录output内的新目录与ZIP，重做使用新版本名；旧版本保留。
辅助JSON与index.html在输出目录，字幕和纯录音在assets内，主ZIP仅四份发布材料。
