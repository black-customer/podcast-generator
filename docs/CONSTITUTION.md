# CONSTITUTION — 产品 DNA（所有决策的最高约束）

> 本文件是产品的宪法。任何里程碑、任何代码决策与宪法冲突时，宪法优先；
> 宪法本身只能由 Bruce（产品所有者）修改。

## 愿景

把 Bruce 脑中的想法，变成**高质量、可像日常播客一样消费的个性化英语输入材料**；
同一流水线顺带成为自媒体内容的一键生产线。

## 不可协商原则

1. **音频质量是最高优先级。** 对齐精度、自然度、响度、无异常段落，优先于任何新功能。
2. **本地优先、零服务器、零额外 API 成本。** 不引入云依赖；唯一外部服务是 Fish Audio TTS（免费档）。
3. **改写环节由 Agent 会话承担。** 工具与 Agent 之间是文件接口（data/ 下的纯文本），
   不集成 LLM API（Bruce 无可用 API 额度，明确拒绝）。
4. **学习方式 = 像听播客一样反复听。** 不做软件引导式学习功能：无学习模式、
   无间隔复习系统、无 shadowing 打分、无 ASR 发音评分。
5. **数据即产品。** data/ 下纯文本结构（问题/中文/英文/剧本）人类可直接读写，
   Agent 可批量读写；任何功能不得破坏这个双向接口。
6. **分享形态零成本。** 未来分享用 zip/skill/插件形态，追求影响力与流量，不盈利。
7. **Bruce 的参与只留在门上**：听感抽查、UI 走查、里程碑验收。其余由 ROADMAP/PROGRESS 驱动 Agent 自主完成。

## 技术栈约束

- Python 3.11 + FastAPI + 原生 JS 前端（无构建步骤、无 CDN）
- ffmpeg 为唯一音频处理依赖；新增重型依赖（torch 类）必须做成可选模块并给出降级路径
- Windows 优先（当前主机），路径处理必须兼容 CJK

## 质量门禁

- `scripts/check.sh` 绿 = 可提交；红 = 禁止提交
- 每个里程碑的验收标准尽量写成可执行测试/脚本
- 一任务一提交；里程碑完成打 tag
