# 前端体验重做 v3

2026-10-15 Bruce批准整体视觉替换，电脑完整备考优先。当前功能与数据规则沿用雅思单题v2，
本轮不增加学习能力、自动转写或评分，不改变后端接口和私人数据格式。

## 已查明问题与对应改动

| 现状证据 | 改动 | 验收依据 |
| --- | --- | --- |
| 每次帮助调用整页innerHTML并滚动到顶部 | 同步骤按稳定标识更新DOM，保留原生表单和媒体节点 | 输入身份、焦点、选区及滚动回归 |

## 具体路径与状态

首页优先继续训练，其次到期复验，否则选新题。题库保留搜索和全部筛选，选中题显示原有回答及
继续练习入口；已保存的中英文正文按需展开。首次作答时录音位于文字输入之前，中文意图和外部
反馈收进可选补充区。Agent/API生成仍沿用原流程和费用边界，音频完成即可自由收听。

训练进入专注布局：返回、Part、五段定位、题目、当前任务。初答确认后理解参考，最多三处的
选择规则不变；逐句先看中文说，帮助使用后转为借助帮助的结果路径。默写保留输入与差异对照，
仍须隐藏英文后口答。新句和新阶段可以回到起点，同句的查看、听音、提示和保存保持位置。

整题按准备、录制、回听、自评呈现。录音中突出停止，保存中阻止重复保存，成功后在同面板回听，
失败保留本机副本并提供原位重试。录音中导航显示原生语义dialog，明确停止保存后离开或继续留在
本页；保存未成功不执行离开。浏览器关闭时仅正在录音／保存触发原生离开保护。

Part2仍有一分钟准备和两分钟回答上限；Part3追问与检查项仍是本人评价，不自动评分。
完成页先显示结果及复验日期，材料、尝试和旧版本历史随后。学习前原话、中文意图和建议分开，
未接触参考的首答条件不变；失败退回、撤销、重复提交和延迟规则继续由领域层校验。

## 实现与兼容

共用样式位于`web/product-ui.css`，增量更新与浏览位置管理位于`web/ui-continuity.js`。
训练调用既有API，服务端与Android领域状态不变。新增前端静态资源加入SW及Android同步清单，
缓存版本递增；PWA进入今日练习。旧路由和旧训练记录继续可用，不批量重生成、不改私人语料。

已有未跟踪试听音频与三组设计目录不属于本任务。历史视觉规范保存在PREVIOUS_DESIGN.md，
不把旧图当新验收图。当前素材只使用合成示例，不包含个人回答、密钥和用户录音。

## 研究依据与验收方式

- [NN/g 可用性原则](https://www.nngroup.com/articles/ten-usability-heuristics/)：保持状态可见、
  使用一致控件、支持恢复并减少记忆负担。
- [NN/g 渐进呈现](https://www.nngroup.com/articles/progressive-disclosure/)：先呈现当前任务，
  帮助和例外按需出现。
- [W3C 触控目标](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum/)：
  本产品主要触控目标采用至少44px的内部标准，另查间距、键盘与焦点。

先执行能在旧实现失败的交互回归，再实现修正；复用既有弱基础默写、熟练口答、延迟失败补练、
Part差异和录音中断测试。批量检查桌面、手机两主题与大字，集中修正一次，再确认。
工程命令与实际结果记入PROGRESS及verification.json。

实际负担改善需真人连续试用：使用一条完整备考路径，记录迷路、找按钮、重复输入、意外跳动、
保存状态不明和中断恢复失败。自动测试仅证明相应行为，不证明“已经达到成熟产品体验”，
不宣称提分或固定时间收益。保留真实听感与实机用户验收门。
