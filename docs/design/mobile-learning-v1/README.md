## 四个入口

今日：继续雅思学习、到期口答、整理一次聊天。材料：聊天和回答的检索、播放、学习。
题库：筛选、随机、回答版本、API 生成。我的：服务和音色、任务、记录、交换文件、存储。
主要操作至少 48px，相邻操作留 8px；正文单列，播放器与底栏互相避让。
四个入口始终可见且只有一个选中，选中项带 `aria-current`；软键盘出现时保持当前输入可见。

## 聊天导入与处理

系统分享、链接、角色标记文字和 TXT/MD/JSON 文件进入同一导入页。先取得原始记录并
落盘，再预览标题、条数、首尾、范围。点击“开始整理”才触发 API；不把链接粘贴本身
当成费用授权。错误保留输入，展示文字/文件兜底，不执行第三方页面脚本。
来源发言保持消息 ID 和原文。角色设定、总结、提示词不作为用户英语口语表现。

状态：已导入→整理英文与来源笔记→生成音频→可听／可练。状态按成果分别显示。
API 断网或结果未知：保存已完成阶段，提示恢复；不自动重复可能收费的未知请求。
结果未知的任务显示“继续处理可能再次计费”，明确的 HTTP 失败保留状态码供排查。
系统强制停止后，下次打开恢复。取消保留原文和已有成果。

## 学习规则

聊天只做情境口答，默认录音，可无录音自评。口答前隐藏英文，提示标记不可撤销，
核对后自评。合理的其他表达同样成功。首次明确求助和有据困难点次日到期，推荐表达
只保存笔记。重复目标保留多个来源；来源中出现正确使用不自动视为长期掌握。

雅思：学习前录音→全部句子整句默写与讲解→看完整中文口答→脱稿口答→回听与复习。
默写、录音和本人自评是不同事实，不互相冒充。首次默写通过后，困难句才进入雅思口答。
两类材料共享每轮最多 10 个单元及 1/3/7/14/30 天日程，同日提交不重复推进。

录音中断保存已录内容，权限拒绝可继续自评；未保存录音离页必须可保留或明确放弃。
已下载材料断网仍可听、练和保存。生成音频采用实测片段边界，估算句内位置明确标注。

## 数据与升级

本机版本化文本/JSON 与媒体放应用私有目录，原子写。Key 仅存在 Keystore 加密存储；
前端只读取是否配置，不落 localStorage。旧 IndexedDB 包先校验并迁移，成功前保留原件。
普通语料包不含私人练习、录音或 Key。个人交换文件带待处理原文和成果，不覆盖手机历史。
