# Release Notes

## v0.6.1 — 旧语料学习解锁与 step5 文本模型（2026-09-29）

### 修复
- **旧语料一键学习**：旧版流水线把原始回答存在 `chinese.txt` 的既有条目（127/129 条）此前
  卡在「缺少原始回答」；现按回退语义（original_answer → chinese → natural_english）生效，
  学习页直接给出「准备／重试材料」，无需手动补原话。已在 3 条真实旧语料上用
  step-5-preview 实测准备成功（讲解忠实、中文原话零虚构错误）。
- **复习库健壮性**：手改坏的非数字事实键不再让 `/api/study/review` 500，其余句子照常返回。
- 「复习库加载失败」的常见原因提示：本地服务若是升级前启动的旧进程，study 端点 404——
  重启服务（update_app.bat / start.bat）即可。

### 变更
- 文本模型默认升级为最强 `step-5-preview`（API 改写与逐句材料准备；设置里显式配过
  `stepfun_text_model` 的不受影响）。TTS 维持 `stepaudio-2.5-tts`。

## v0.6.0 — 逐句学习模式与暖纸自习室（2026-09-29）

L02+L03 落地：生成音频之后可以真正「学」一道题；全应用电脑端换成暖纸视觉。

### 逐句学习（电脑端）
- 学习顺序固定：学习前录音 → 完整回答逐句默写与讲解 → 看完整中文口答 → 只看原题脱稿口答 →
  录音对比与句子复习。
- 默写按词分框（标点在框外、缩写一框、空格/Tab/退格/整句粘贴顺序流转）；提示 3/5/8 秒可设、
  淡出不清空输入；「播放本句」优先播放经指纹核对的时间轴，无法核对时回落完整音频并说明。
- 讲解有证据边界：只有原始回答里的英文原话能证明错误时才出现「你的原始表达」分析；
  中文或混合输入不虚构英文错误（真实模型抽查通过）。
- 三类录音（学习前/看中文/脱稿）分版本保存在本机，不进语料包与发布物；总结只列实际练习，
  不给未经验证的雅思或发音分数。写错、用过提示和收藏的句子进入句子复习库。
- Agent 模式：音频照旧 `pipeline.py complete`，另有独立 `pipeline.py study` 提交逐句材料；
  API 模式音频完成后自动准备一次材料，失败不影响音频。

### 暖纸自习室桌面视觉
- 电脑端（≥861px）统一暖米背景、浅纸阅读面、墨棕正文、橄榄绿主操作；手机端维持原布局，
  收听与导入不受影响（APK 已含全部新前端资产）。

### 诚实与安全修复
- 播放器同步模式标注改为三态：逐词同步（fish.audio SSE）/ 逐句同步（默认 StepFun）/
  基础同步；README 不再无条件承诺「逐词点亮」。
- update_app.bat 只结束本项目的服务进程（祖先进程校验），不再强杀恰好占用 8765 的无关软件。
- portable zip 排除开发用设计交接图，体积从 43MB 回到约 1.3MB。
- check.sh：ruff 缺失改为硬失败；新增 --release 模式（单测+e2e+打包审计一次跑齐）。

### 下载
- Windows 可移植包 `ielts-pod-portable.zip`：解压双击 start.bat 即用；
- Android `ielts-pod-v0.6.0-debug.apk`：安装后从电脑端导入语料包（ZIP 或局域网直传）。

## v0.5.0 (beta) — 可分享版重构 R01–R05（2026-09-21）

面向公开分享的第一版：一条主链（选题 → 作答 → Agent/API → StepFun 音频 → 精听 → 安卓离线）。

### 新引擎
- StepFun StepAudio 2.5 TTS 成为默认语音引擎（模型固定 `stepaudio-2.5-tts`），fish.audio 降为备选；
  旧安装已配 Fish Key 的保持不变，不自动迁移密钥。
- 逐行对话合成（提问者/回答者独立音色，默认 280ms 间隔），24kHz 输出统一重编码 44.1kHz 后拼接；
  429 遵循 Retry-After 有限退避；复用既有 QA 门禁与 -16 LUFS 母带链。
- 真实验收：5 条代表语料 QA 全 pass、时长比 1.02–1.19（无变速/截断/异常停顿）。

### Agent/API 双模式
- 提交回答时可选：Agent 模式（默认）一键复制指令给任意编码 Agent，完成后网页自动跳转；
  API 模式用同一 StepFun Key 一次完成改写→校验→合成（step-3.7-flash JSON Mode，
  结构失败自动修复重试一次；无文本权限时明确提示改用 Agent 模式，不静默降级）。
- `original_answer.txt` 永远保存原始回答；改写失败不覆盖、不产生音频。
- Agent 执行入口：`skills/ielts-audio/SKILL.md` + `pipeline.py complete`（先校验后原子写入）。

### 已批准 UI（docs/design/v1）
- 品牌 IELTS Pod；导航收敛为 开始练习 / 我的语料 / 正在播放 / 设置；默认入口「开始练习」。
- 我的语料只有 雅思口语 / 日常表达 两个分类；普通界面移除独白/整集/多轨术语。
- 设置页 = 双引擎卡 + 提问的人/回答的人角色卡（性别→音色联动→试听）；首配向导三步完成。
- Android：ZIP 文件 + 手动局域网两种导入；模拟器实测导入与逐词点亮播放通过。

### 分享与运维
- `scripts/doctor.py`：只读环境诊断（Python/ffmpeg/依赖/配置/题库/端口），绝不输出密钥。
- `run.py` 启动前置检查：端口占用显式报错（不静默连旧服务）、ffmpeg 缺失给安装提示。
- `scripts/package.py` → `dist/ielts-pod-portable.zip`（内置审计：零密钥/零个人语料/零音频）。
- README 重写：真实仓库地址、一条主流程、可直接发给 Agent 的安装指令。
