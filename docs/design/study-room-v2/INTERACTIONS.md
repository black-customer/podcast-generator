# 桌面端交互与文案规范（开发依据）

2026-09-29 Bruce 决定。此文件描述目标行为；桌面学习模式已在 L02/L03 实现。
图片用于布局和视觉参考，生成图片里的字词、数值或阶段偶有偏差时以这里为准。

## 1. 音频完成后，用户选择听或学

选题与原始回答保持现有 Agent/API 双模式。系统保留原话，先完成可播放的自然英文音频；
逐句中文和讲解另有「准备中／已就绪／待补齐／失败」状态。音频不等待讲解即可收听和下载。
学习入口在完成页、语料条目及精听播放器；材料缺失时说明缺什么，提供准备或重试动作。
旧语料可以继续收听。`pipeline.py complete` 仍只接受三份英文文本；逐句材料由独立的
`pipeline.py study` 命令或音频完成后的 API 材料任务准备。

## 2. 每道题的固定顺序

1. **学习前录音**：只显示原题；录制、停止、回听、保存。完成的录音被保留。
2. **逐句默写**：按照完整回答的顺序，逐句显示对应中文意思和每词一个空；全部句子都练。
3. **本句讲解**：默写检查通过后，展示对应英文、为何这样组织、搭配／知识点；
   原始输入有可核对的错误才增加个人错误分析。用户点击「下一句」。
4. **看中文完整回答**：展示原题和整个回答的中文意思，用户连贯录一遍，保存录音。
5. **只看原题完整回答**：隐藏中文和英文参考，用户再录一遍，保存录音。
6. **总结与复习**：事实性列出已完成句子、曾写错／用提示的句子、三类录音与重录历史。

每次录音的停止、回听和重录是当前步骤中的状态，重录不悄悄覆盖既有已完成录音。
退出后按题保存进度；返回时恢复当前句及已填写内容，已完成录音仍可查看。

## 3. 整句默写

- 第 N / M 句显示中文意思，下面按示范英文的词序显示 N 个空；标点在词框外，
  `I'd` 等带撇号的缩写保持一个词框。长句跨行，但词序及焦点路径不变。
- 输入空格或 Tab 后进入下一框，退格可回上一框。粘贴或输入整句时顺序分配至词框。
- 三个操作固定可见：「播放本句」「短暂看答案」「检查答案」。播放仅作用于当前句。
- 提示完整显示当前英文 5 秒后淡出；可设置 3／5／8 秒。已输入文字在显示、淡出、
  隐藏三个状态始终保留。系统设置减少动画时直接隐藏。
- 用户每次提交后再反馈，避免逐键打断。未填完明确标记空框；能确定的拼写错误定位到词。
  对开放改写或合理替代表达，显示「与示范不同，请对照检查」，不冒充语义或雅思评分。
- 用过提示、写错过、提交后修正均记录实际经过；修正写对后仍可查看本次经过。
- 一句通过并显示讲解后，出现「下一句」。最后一句通过后进入看中文完整口答。
- 如果用户无法完成，可保存并退出；重进后继续当前句。复习模式同样使用整句默写。

## 4. 讲解的证据边界

每句学习材料需要：完整中文意思、自然英文、播放位置、组织方式解释、相关词法／搭配。
原始回答可以是中文、英文或中英混合，系统应忠实解释原意，不能添情节或把中文造为用户的
英文错句。原始英文确实有错误时，列出原句、具体问题与正确形式；只有文字不能诊断发音。
例如 `It helps me relax.` 同样成立，不能因为示范写 `unwind` 就判作语言错误。
学习时的首段录音仅用于用户回听对比；若尚无经核查的转写，讲解不得声称已诊断该录音。

## 5. 录音、保存与恢复

- 每个题目保留「学习前／看中文／脱稿」三类录音及同类重录版本，记录时间和时长。
- 麦克风权限拒绝、设备缺失：说明如何恢复，并允许离开当前步骤或保存已有进度。
- 保存失败：如果录音仍在本页内存中，提供重试保存和下载当前录音；不能说已经保存。
- 回听两段录音时逐段播放，避免同一时间两个音源竞争。
- 删除时明确是哪一段录音。操作只影响选中的录音。
- 练习结果以「未看提示写出／用过提示／仍需再练／本人自评」等具体事实呈现。

## 6. 句子复习

写错过、用过提示、手动收藏的句子进入复习库，可按来源题目筛选。
列表默认显示中文与来源；进入句子详情才能查看完整示范和讲解。
开始复习后先看中文做整句默写，之后反馈并保留这轮结果。
空库显示「暂无待复习句子」，引导回到选题；不生成虚构到期或能力分数。

## 7. 全局异常和可用性

题库筛选无结果、生成失败、学习材料缺失、单句音频不可用、语料包导入失败均提供
一条清楚的恢复路径。语料包导入仅使用现有支持的 ZIP 格式；页面示意不得声称支持
其他表格文件。文本可选择复制；焦点清楚；错误有文字；长中文可滚动且录音控件保持可达。
